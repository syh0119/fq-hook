# 番茄导出（fq-hook）

番茄小说（`com.dragon.read`）的 **LSPosed 模块**：把已解密到本地的章节正文导出成 **TXT / EPUB**，
EPUB 含**插图与章节目录**，导出过程有**进度条**，导出后自动与**原始排版 XHTML 逐章校对**。

> 本模块**不实现任何解密算法**，也不碰密钥推导。它运行在番茄进程内，直接调用宿主自己的
> native 解密例程，然后把明文结果落盘。

---

## 功能

| 功能 | 说明 |
|---|---|
| 手动导出 | 章节先进内存缓冲，点设置面板里的「导出本书」才写出整本。默认不自动落盘 |
| 两种格式 | `TXT`（纯文本，插图处留占位）／ `EPUB`（插图嵌正文 + 章节目录），默认 TXT |
| 插图 | 从宿主私有目录读出明文 JPEG/PNG，EPUB 内嵌、TXT 模式另存 `插图/` 子目录 |
| 目录 | EPUB 2.0.1 + `toc.ncx`，一章一条 `navPoint`，可直接导入阅读器跳章 |
| 进度条 | 解析章节 → 打包 EPUB → 校对，分阶段实时进度与状态文案 |
| 校对 | 导出后把结果与**原始排版 XHTML** 逐章比对（字数、块、插图），产出 `_校对报告.txt` |
| 设置界面 | 挂在番茄「我的」页底部固定栏，点开即模块设置面板 |

---

## 原理

模块从不实现 AES，也不解析密钥表 —— 全部借助宿主：

```java
com.dragon.read.crypt.CryptManager
    byte[] decrypt(String 密文, String 书级key, int keyVer)   // public static native
```

实现在宿主的 `libdragon_crypt.so` 里，返回值恒为 gzip，解压即 XHTML。

四个 hook 点协同：

| 落点 | 作用 |
|---|---|
| `ChapterInfo.a(ItemContent, boolean)` | 下载/读取瞬间拿到 密文 + 书名 + 章节名 + chapterId + keyVersion |
| `DecryptKey.<init>` | 旁听书级密钥（v2 key + mVer），宿主给什么用什么 |
| `reader.utils.n.a(ChapterInfo, DecryptKey)` | 阅读器解密入口，返回**已解压明文**，覆盖「已下载从 DB 读」的路径 |
| `CryptManager.decrypt` | 被动兜底截获 |

UI 注入挂在 `androidx.fragment.app.Fragment` 基类上，用**文本锚点**（「我的订单」等）识别页面，
不依赖类名与混淆 id，因此对宿主改版天然免疫。

## 安装

1. 安装 `dist/fq-hook-lsp-v1.6.1.apk`
2. LSPosed 里启用模块，作用域勾选 **番茄小说**（`com.dragon.read`）
3. 强行停止番茄后重新打开
4. 进入番茄「我的」页，底部会出现 **「🍅 番茄导出设置」** 入口

## 使用

1. 打开一本书读几页，或点一次「下载」——章节会进入模块的内存缓冲
2. 回到「我的」页 → 「番茄导出设置」
3. 选导出格式（TXT / EPUB），点 **「导出本书」**
4. 输出目录：`/sdcard/Download/番茄导出/<书名>/`

```
<书名>.txt               纯文本
<书名>.html              图文混排（TXT 模式附带）
<书名>.epub              插图 + 目录（EPUB 模式）
插图/i0001.jpg …         插图本体
_校对报告.txt            与原始 XHTML 的逐章核对结果
_运行日志.txt            模块运行日志
_开关.txt                开关配置（与设置面板双向同步）
```

**为什么必须手动点**：实测番茄把「读过的章节」也缓存到
`files/<uid>/prefix_public_<bookId>/<chapterId.hashCode()>`，与「用户点下载」在
解密层面完全同构（同路径、同 boolean 参数、同调用栈、无系统通知），自动分辨不出来。
所以由用户按一下来表态。

## 校对报告

导出后自动生成，也可以在设置面板点「校对报告」查看：

```
《书名》导出校对报告
时间 2026-10-10 01:35:17
格式 EPUB
──────────────────────────────
导出结果  ✔ 导出 EPUB《书名》 7/7 章 · 插图 0 张 · 33 KB
章节      7 / 7
正文      18,989 字  |  原始 XHTML 18,989 字  |  偏差 +0
插图      0 / 0 张
──────────────────────────────
结论      ✔ 与原始排版一致，未发现丢字/丢块
```

口径：源侧把原始 XHTML 去标签后数**非空白字符**，导出侧数最终落盘内容，两边**独立计算**，
所以能真实暴露解析中断、块丢失、图注被吞。差异 > 0 时会列出逐章明细与解析为空的章节清单。

## 构建

无 Gradle，纯手工链路（`aapt2` + `javac` + `d8` + `zipalign` + `apksigner`）。
`build.sh` 里的 `TOOLS` / `SDK` / `KS` 三个变量指向本机 Android SDK build-tools、
`android.jar` 与签名 keystore，按自己的路径改掉即可。

```bash
bash build.sh
# 产物: out/fq-hook.apk
```

`lib/api-82.jar` 是编译期依赖（Xposed API），不打进 APK。

## 已知边界

- **整本导出的前提**是模块捕获过该书的章节：想导整本，得先让番茄把章节过一遍
  （读一遍或点一次下载）。原因：下载目录里的文件名是 `chapterId.hashCode()`，
  hash 不可逆，无法只靠扫目录还原整本。
- 缓冲在内存里，番茄进程重启即清空。
- 单次捕获上限 5000 章/本。
- EPUB 的插图路径已由离线测试覆盖（构造多章多图，校验图片文件与正文引用），
  真机侧需翻到含插图的章节才能看到 `插图 N 张`。
